# PersonalPortfolio

Welcome — and thank you for reviewing my portfolio.

This repository showcases selected projects that demonstrate my analytical approach and technical skills across **Data Analysis, Data Science, and Business Intelligence**. Each project highlights how I explore data, build insights, and structure solutions to support decision-making.

Some assets — including **Power BI reports (.pbix)** and **HTML visualizations (.html)** — cannot be previewed directly on GitHub.  
If you'd like to explore them:

• **.pbix files:** Download and open in **Power BI Desktop**  
• **.html files:** Download and open directly in your browser (just double-click once it is in your "Downloads" folder)
